# Meu Repositório de Projetos

Repositório com os projetos, atividades e trabalhos desenvolvidos durante meus estudos em programação e desenvolvimento de software.

## 📁 Estrutura do Repositório

### 🗄️ Banco de Dados

Projetos e exercícios relacionados a modelagem de dados, diagramas entidade-relacionamento (DER), consultas SQL e desenvolvimento de bancos de dados.

### 💻 Projetos Portugol Studio

Algoritmos e exercícios desenvolvidos em Portugol Studio, focados em lógica de programação, estruturas de decisão, repetição e resolução de problemas.

### 🌐 Programação Web

Projetos voltados para o desenvolvimento web utilizando HTML, CSS e JavaScript, incluindo páginas responsivas e aplicações interativas.

### 💡 PTIC — Projetos de Tecnologias da Informação e Comunicação

Trabalhos, pesquisas, apresentações e projetos desenvolvidos na disciplina de PTIC.

### 🔌 Sistemas Embarcados

Projetos envolvendo eletrônica, Arduino e Internet das Coisas (IoT), utilizando simuladores como Tinkercad e programação em C++.

## 👨‍💻 Sobre Mim

Sou estudante e apaixonado por tecnologia, programação e desenvolvimento de software. Este repositório reúne minha evolução prática através de projetos desenvolvidos em diferentes áreas da tecnologia, desde lógica de programação e banco de dados até desenvolvimento web e sistemas embarcados.
